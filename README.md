## About

A bot that schedules reminders and nags at the right time.

## Features

- Event-driven bot core with a clean command registry
- Built on node:events, no framework required
- Debug logging and typed events
- Drop-in adapters for any messaging API

## Install

```bash
git clone https://github.com/synrayx/reminderbot.git
cd reminderbot
```

## Usage

```bash
npm install
cp .env.example .env
npm start
```
